# CRUD Prueba

Proyecto de práctica desarrollado durante residencia profesional.

## Tecnologías

- Laravel 13
- MySQL
- React
- Axios

## Arquitectura

Backend:
- Controller
- Service
- Repository
- Model

Frontend:
- React
- Axios

## Estructura

CRUD_prueba/
├── backend/
└── frontend/

## Instalación

### Backend

cd backend

composer install

php artisan migrate

php artisan serve

### Frontend

cd frontend

npm install

npm run dev
